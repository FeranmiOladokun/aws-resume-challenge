# AWS Cloud Resume Challenge

After passing the AWS Cloud Practitioner and Solutions Architect – Associate exams, I wanted to put what I learned into practice. This project is my attempt at the [AWS Cloud Resume Challenge](https://cloudresumechallenge.dev/docs/the-challenge/aws/).

I first worked with AWS in my technical support role at Geoplex Drillteq. Since returning to Poland, I've been studying toward a cloud role, using free time and train commutes to my day job. This is where I'll document the build and what I learn along the way.

I'm starting with a resume template so I can spend more time on the AWS side: S3 and CloudFront for the website, and API Gateway, Lambda, and DynamoDB for a visitor counter. I'll add Terraform and GitHub Actions as I progress.
